# Dataset attribution

Almeida, T. and Hidalgo, J. (2011). **SMS Spam Collection** [Dataset]. UCI Machine Learning Repository. DOI: [10.24432/C5CC84](https://doi.org/10.24432/C5CC84).

- Source: https://archive.ics.uci.edu/dataset/228/sms+spam+collection
- Download: https://archive.ics.uci.edu/static/public/228/sms+spam+collection.zip
- Retrieved: 26 October 2026
- License stated by UCI: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)
- Original source text and readme are retained in this directory.
- `cleaned_sms.csv` is a derived version: surrounding whitespace trimmed, exact duplicate message text removed, labels numerically encoded and source identifiers added.
- The original corpus includes unsolicited promotional content and historical contact details; these are data for analysis, not contact recommendations.
